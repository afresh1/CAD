Vario Grounds Basket -- Blind Shaker Holder
===========================================

This is a model of a Baratza Vario grounds basket, plus a cutout
for an MHW-3BOMBER blind shaker that I use.  This makes grinding
directly into the blind shaker incredibly easier.
